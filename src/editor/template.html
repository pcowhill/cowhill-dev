Edit the cowhill.dev project catalog

This editor opens the repository's projects.yaml, lets you edit projects with a form or as raw YAML, previews how they render on the website, and saves the file back. It works offline from your computer and never contacts GitHub.

…or drag projects.yaml onto this window.

How publishing works
  1. Download or clone the cowhill-dev repository so you have projects.yaml and project-editor.html side by side.
  2. Open projects.yaml here, edit, preview, and Save. In browsers without direct saving, use Download YAML and replace the repository's projects.yaml with the downloaded file (it may have been renamed, for example projects (1).yaml).
  3. Put any images in project-assets/<project-id>/ yourself. Use Open repository folder to preview them and check that referenced files exist.
  4. Commit and push to main. GitHub Actions validates and deploys the website; a local save changes nothing online until it is committed and pushed.

This repository is public. Drafts are excluded from the website but remain readable on GitHub. Do not store secrets or sensitive material in the catalog.

Previews use the deployment configuration to decide which links are internal.
